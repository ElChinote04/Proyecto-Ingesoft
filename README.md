# Proyecto Ingesoft

## Requisitos
- Node.js v20+
- npm v10+

## Instalación

### 1. Clonar el repo
git clone <url-del-repo>
cd <nombre-del-repo>

### 2. Configurar variables de entorno
cp .env.example .env
# Completar los valores en el archivo .env

### 3. Instalar dependencias

# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install

## Correr el proyecto

# Backend
cd backend
npm run dev

# Frontend
cd frontend
npm run dev
