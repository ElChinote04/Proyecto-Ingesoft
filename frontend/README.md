# SAGE · Frontend

React 19.3.0 y Vite 8.3.1, JavaScript/JSX y CSS. Consume la API REST con cookies HttpOnly.

La instalación sin seed y los requisitos están en el [README principal](../README.md). La [guía del flujo completo](../docs/FLUJO_COMPLETO.md) recorre instalación, usuarios, catálogos, matrícula, asignación, sesión y asistencia con comprobación de cada operación.

Desde esta carpeta: `npm run dev`, `npm run lint`, `npm run build`.
La URL de la API se configura en `.env` con `VITE_API_URL`.
